# SEO Routine Configuration

Version 4, generated by `/seo-routine calibrate` on YYYY-MM-DD. Re-run calibrate to upgrade.
Effective settings and active experiments live in this repository. Historical weekly folders and
scorecards keep their original labels and definitions. New runs use the actual ISO week plus a run date.

The publisher opens a PR only when that action is inside the session's authorized workflow. A request
for local implementation or commit-only work stays local. If a push to the base branch deploys
production, follow the repository's delivery rules. The skill never creates or alters scheduled jobs
merely because autopilot is enabled.
