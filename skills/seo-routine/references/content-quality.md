# Content Quality & E-E-A-T Reference

## E-E-A-T Scoring Rubric

Each factor scored out of 25 points (total: 100).

| Factor | Score | Key Signals |
|---|---|---|
| **Experience** | /25 | Original research, case studies, before/after results, personal anecdotes, process documentation, unique/proprietary data, photos/videos from direct experience |
| **Expertise** | /25 | Author credentials and certifications, relevant professional background, technical depth appropriate for audience, accurate well-sourced claims, author bio |
| **Authoritativeness** | /25 | External citations and backlinks from authoritative sources, brand mentions, industry recognition, published in recognized outlets, cited by other experts |
| **Trustworthiness** | /25 | Contact info and physical address, privacy policy and ToS, customer testimonials/reviews, date stamps, transparent corrections, HTTPS |

## AI Citation Readiness Checklist

Optimization signals for AI search engines (ChatGPT, Perplexity, Google AI Overviews, AI Mode).

| Signal | Details |
|---|---|
| Answer-first format | Lead with direct answers to key questions before elaboration |
| Quotable passages | Clear, concise extractable facts (134-167 words ideal for citation) |
| Structured Q&A | Question-answer patterns, definition formats, step-by-step instructions |
| Attribution | Source citations within content; clear brand/author/concept definitions |
| Structured data | Article, FAQ, Organization, Person schema markup |
| Tables and lists | Comparative data in scannable formats |
| Heading hierarchy | Strong H1 > H2 > H3 flow for AI parsing |
| First-party data | Original research, statistics, case studies, unique datasets |
| Topical authority | Content clusters demonstrating deep expertise (not isolated pages) |
| Multi-platform tracking | Monitor Google AI Overviews, AI Mode, ChatGPT, Perplexity, Bing Copilot |

## Word Count Minimums by Page Type

| Page Type | Minimum Word Count | Notes |
|---|---|---|
| Homepage | 500 | |
| Service page | 800 | |
| Blog post | 1,500 | |
| Product page | 300+ | 400+ for complex products |
| Location page | 500-600 | |

These are topical coverage floors, not targets. Word count is not a direct ranking factor. A shorter page that thoroughly answers the query outranks a longer page that does not.

## Content Freshness Signals

- Publication date visible on page
- Last updated date shown if content has been revised
- Content older than 12 months without update flagged for fast-changing topics
- Regularly updated data improves GEO quotability

## Readability Targets

| Metric | Target |
|---|---|
| Flesch Reading Ease | 60-70 (general audience) |
| Grade level | Match target audience |
| Average sentence length | 15-20 words |
| Paragraph length | 2-4 sentences |

Flesch Reading Ease is not a direct Google ranking factor (confirmed by John Mueller; deprioritized by Yoast in v19.3). Use as a content quality indicator, not an SEO metric to optimize directly.

## AI Content Assessment Markers

### Acceptable AI Content
- Demonstrates genuine E-E-A-T
- Provides unique value
- Has human oversight and editing
- Contains original insights

### Red Flags (Low-Quality AI Content)
- Generic phrasing, lack of specificity
- No original insight or first-hand experience
- Repetitive structure across pages
- No author attribution
- Factual inaccuracies
- No human editorial oversight evident

The Helpful Content System was merged into Google's core ranking algorithm (March 2024 core update). Helpfulness signals are now weighted within every core update continuously.
