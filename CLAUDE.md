# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What This Repo Is

A **Claude Code marketplace plugin** (`vladuma/seo-routine`) that provides a data-driven weekly SEO optimization routine. The repo itself is not a runnable application — it's a plugin distributed via Claude Code's plugin system.

## Architecture

**Two-layer design:**

1. **Marketplace wrapper** (repo root) — `.claude-plugin/marketplace.json` indexes the plugin for discovery
2. **Plugin** (`skills/seo-routine/`) — the actual installable unit
   - `SKILL.md` — core engine with all phase logic (command router, calibration, analyze/plan/implement/review)
   - `.claude-plugin/plugin.json` — plugin manifest
   - `scripts/` — Python automation scripts (DataForSEO API wrapper, keyword research, SERP analysis, competitor gap, backlinks, self-crawl audit)
   - `references/` — SEO/GEO knowledge base (algorithm docs, checklists, schema templates)
   - `templates/` — scaffolding files generated by `calibrate` into target projects
   - `skills-ref/` — sub-skill reference docs (gap-finder, competitor-intel, brand-writer)

All script/reference paths in SKILL.md are relative to the plugin root (`skills/seo-routine/`).

## Key Files

- `skills/seo-routine/SKILL.md` — the main skill definition; this is where phase logic lives
- `skills/seo-routine/scripts/dataforseo_api.py` — shared API wrapper used by all DataForSEO scripts
- `skills/seo-routine/scripts/credential.py` — reads `DATAFORSEO_LOGIN`/`DATAFORSEO_PASSWORD` from env
- `docs/design-spec.md` — full design specification (scoring model, data sources, directory structure, rate limits)

## Python Scripts

Scripts use only stdlib (`urllib`, `json`, `base64`) for DataForSEO calls — no `requests` dependency at runtime. The `requirements.txt` lists Google API client libraries (for GSC/GA4 integration) and `python-dotenv`.

Run scripts from `skills/seo-routine/scripts/`:
```bash
cd skills/seo-routine/scripts
python3 keyword_research.py <keyword>
python3 serp_analysis.py <keyword>
python3 domain_overview.py <domain>
```

Scripts require `DATAFORSEO_LOGIN` and `DATAFORSEO_PASSWORD` env vars.

## Plugin Commands

When installed in a target project, the skill exposes:
```
/seo-routine calibrate    # one-time setup
/seo-routine analyze      # collect data, score opportunities
/seo-routine plan         # select top items, create weekly plan
/seo-routine implement    # execute in git worktree (seo/YYYY-WNN branch)
/seo-routine review       # compare predictions vs actuals
/seo-routine status       # current state
/seo-routine goals "..."  # set strategic goal
```

## When Editing

- **SKILL.md changes** affect all users of the plugin — test the full command flow (calibrate → analyze → plan) mentally before modifying phase logic
- **Scoring model** (composite scores, weight adjustment) is defined in design-spec.md and implemented in SKILL.md — keep them in sync
- **Template changes** (`templates/`) affect what `calibrate` generates in target projects — existing users won't see changes unless they re-calibrate
- Scripts output compact structured formats (e.g., `keywords[N]{keyword,volume,difficulty}:`) designed for LLM consumption, not human-readable tables
